# Sponge MCP bundle

Save articles and PDFs to a reading library captured by a computer you control. Highlight passages, keep notes, and find ideas through search or your coding agent.

This bundle connects an MCP client, such as Claude Desktop, to the Sponge tools already on your computer. It contains a small launcher and no copy of Sponge.

## Before you install

Install the Sponge command with Node.js 24.20.0 or newer: `npm install --global @hraness/sponge`. The launcher checks that the installed command is the official package at version 0.81.0 or newer before it starts.

See the [setup guide](https://sponge.computer/docs/agents) for the supported connections and the first task.
