# Yaptake MCP bundle

Edit video for every feed (9:16, 4:5, 1:1 or 16:9) in a native Mac app with a transcript, captions and timeline. Local tools let coding agents work on the same project.

This bundle connects an MCP client, such as Claude Desktop, to the Yaptake tools already on your computer. It contains a small launcher and no copy of Yaptake.

## Before you install

Install [Yaptake](https://yaptake.com) 0.1.0 (build 231) or newer in Applications on a Mac with Apple silicon and macOS 26.0 or newer. Open a saved project in Yaptake before you ask for an edit. The launcher checks the app's identity, version and developer signature before it starts the app's own MCP server.

See the [setup guide](https://yaptake.com/docs/agents) for the supported connections and the first task.
