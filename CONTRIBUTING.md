# Contribute

Use Node.js 24 and run `npm run check`. Keep a source change separate from its
runtime qualification: failed or unpublished inputs must preserve the admitted
package. Add focused fixtures for a changed validation or packaging boundary.

Follow the [documentation guidelines](DOCUMENTATION_GUIDELINES.md),
[README guidance](README_GUIDELINES.md) and [writing style](STYLE.md). Product
instructions must reach a supported task and preserve their local-data and
permission boundaries. Report only checks that actually ran.

Submit a pull request. Changes merge through the protected path after the
required check passes. Do not commit credentials, private source, user data,
generated download caches or planned events as verified publications.
